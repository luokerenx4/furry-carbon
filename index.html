TECHNICAL DEEP DIVE

Three.js 实时高质量生物毛发渲染 — 核心架构与 Best Practices

01

混合双层被毛架构 (Hybrid Shells + GPU Instanced Blades)

真实哺乳动物拥有双层被毛 (Dual Coat)：底层致密绒毛负责体积覆盖与防露底，外层针毛（Guard Hairs）负责轮廓毛刺感、聚簇纹理与高光动态。

  • 底绒层 (Volumetric Undercoat Shells)：使用多层沿法线微距挤出的半透明噪声切片模拟高密度绒毛体积，以极低算力消除皮肤硬边。
  • GPU 实例化多段曲率毛束 (Instanced Curved Ribbons)：单次 Draw Call 渲染最高 120,000 根 5 段式锥形弯曲发片，全部曲线形变、朝向对齐在 Vertex Shader 内完成。
02

拒绝“牙刷感”：Voronoi 聚簇 (Clumping) 与多频卷曲

新手做毛发最常见的问题是毛发像塑料刷子一样均匀散开。生物毛发受皮脂与静电影响，毛尖会向局部簇中心收拢成束（Clumps）。

  • 分层聚簇模型：为每根毛发预计算所属毛簇的锚点与法线帧，沿发根到发尖按 pow(h, clumpCurve) 收拢，保留蓬松发根的同时形成自然尖端毛束。
  • 切线空间螺旋与毛躁：在每根毛发的正交切线基（Tangent-Bitangent Frame）叠加螺旋正余弦波（泰迪卷毛）与高频噪声（Frizz），避免单调直线。
03

解剖学分区遮罩 (Anatomical Region Masking)

同一只宠物全身毛长绝非均等——如果口鼻与眼周和脖圈一样长，五官会被彻底淹没。

  • SDF 有机网格与连续解剖权重：本系统采用光滑距离场（Smooth SDF）构建无接缝有机皮肤，杜绝多球穿插造成的内部无效毛发浪费。
  • 独立分区控制：眼周与鼻头自动压短并退避密度；脖圈围脖（Mane）、耳簇、尾巴大毛球、肚皮软绒各自拥有独立毛长倍率。
04

Kajiya-Kay / Marschner 双高光与逆光透射 (SSS)

如果直接用常规 Lambert / PBR MeshStandardMaterial 渲染毛发，毛团会显得像灰暗粗糙的石头，缺乏丝绸光泽与空气感。

  • 双各向异性高光瓣 (Dual Shifted Specular Lobes)：模拟毛鳞片倾斜角（Cuticle Tilt），第一层高光向发尖偏移呈冷白光泽（表面反射 $R$），第二层向发根偏移并叠加毛发色素与虹彩（内部透射反射 $TRT$）。
  • 逆光边缘散射与根部自阴影：当光线从宠物背后穿透毛尖时计算前向散射（Rim Backlight SSS），配合发根指数级 AO 与体积方向阴影，瞬间营造出温暖“想rua”的空气绒感。
05

零 CPU 遍历开销的弹簧惯性与 GPU 梳剪缓冲区

十万根毛发若每帧在 CPU 计算物理会直接拖垮帧率。最佳实践是粗粒度刚体角速度/线速度弹簧解算 + 逐顶点延迟传递：

  • 全局/骨骼弹簧场 + 相位延迟：CPU 仅解算呼吸、歪头、摇尾、抖毛与相机拖拽惯性弹簧，Shader 根据高度 h² 放大弯曲并注入高频风场湍流。
  • 增量式交互属性缓冲 (Grooming Attributes)：梳刷、修剪、生毛、挑染只更新射线命中半径内的局部实例 Buffer 子区间（addUpdateRange），实现 60FPS 丝滑实时撸宠与修毛。
06

工程落地与移动端分级 (LOD & Production Tips)

在实际商业项目（3D 潮玩互动、虚拟宠物、车载助手）落地时的性能分级建议：

  • 桌面高端档：60k~100k 5段式刀片毛丝 + 12~16 层底绒 Shell + MSAA 4x。
  • 移动端中端档：降级为 15k~25k 3段式稍宽发片 + 8 层底绒 Shell，提高 rootThickness 约 1.4 倍以保持同等视觉饱满度。
  • 远景 LOD：距离拉远时平滑淡出外层几何针毛，仅保留多层底绒 Shell + 各向异性法线高光贴图，Draw Call 恒定极低。
